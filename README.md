# WorkTrack Telegram Bot

Telegram-бот для учёта рабочего времени по задачам за день с автоматической отправкой отчётов на Email и обогащением сводки данными из внешних API с TTL-кешированием в SQLite.

## Возможности
- Добавление задач и затраченного времени за день (FSM).
- Подсчёт итогового времени и вывод списка задач за текущую дату.
- Сохранение Email пользователя в SQLite для отправки отчётов в один клик и возможность смены адреса.
- Интеграция с внешними REST API без ключей регистрации:
  - Курс USD от Национального банка Республики Беларусь (НБРБ).
  - Текущая погода (Open-Meteo).
- Персистентное кеширование ответов внешних API в SQLite с настраиваемым TTL.
- Отправка ежедневного отчёта на Email через асинхронный SMTP.

## Архитектура
- `bot/config` — конфигурация и валидация переменных окружения.
- `bot/domain` — доменные сущности и контракты (`Protocol`).
- `bot/application` — бизнес-логика трекера и формирования отчётов.
- `bot/infrastructure` — SQLite-репозитории, TTL-кеш, клиенты внешних API и SMTP.
- `bot/presentation` — FSM-состояния, клавиатуры и обработчики `aiogram`.

## Локальный запуск
1. Скопируйте `.env.example` в `.env` и заполните токен бота и настройки SMTP:
   ```bash
   cp .env.example .env
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите бота:
   ```bash
   python -m bot.main
   ```
